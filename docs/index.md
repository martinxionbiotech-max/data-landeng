# LanDeng Open Datasets

Machine-readable, link-worthy knowledge datasets for the LanDeng (澜灯) platform — Chinese botanical incense, documented in English with source transparency.

| Dataset | File | Status |
|---|---|---|
| Ingredient database | [datasets/ingredients.json](datasets/ingredients.json) | live (94 entities) |
| Terminology database | [datasets/terminology.json](datasets/terminology.json) | live (104 terms, CC BY-SA 4.0) |
| Aroma database | [datasets/aroma.json](datasets/aroma.json) | live (10 aroma families) |
| Material database | [datasets/materials.json](datasets/materials.json) | live (15 entities) |
| Comparison database | [datasets/comparisons.json](datasets/comparisons.json) | live (17 profiles) |

All datasets use Schema.org `Dataset` + `DefinedTerm` structures. See [Format & Governance](format.md).
