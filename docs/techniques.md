# Technique Database

12 Chinese incense techniques — heating, pressing, blending, appreciation, and carrying methods — as `DefinedTerm` entities.

Fields per entity: `termCode` · `name` · `alternateName` (Chinese, pinyin) · `description` · `additionalProperty` (Type / Period / Materials / Equipment / Smoke level / Related) · `sources` (Source Objects, where a source page exists).

| termCode | Name | Type |
|---|---|---|
| indirect-fire | Indirect-Fire Incense (隔火焚香) | heating (warm, not burn) |
| seal-incense | Seal Incense (篆香) | powder-pressing + timekeeping |
| hexiang-blending | 合香 Blending (合香) | compound blending |
| incense-appreciation | Incense Appreciation (品香) | appreciation |
| incense-ceremony | Incense Ceremony (香道) | ceremonial art |
| pill-forming | Pill Forming (香丸) | forming (roll pellets) |
| sachet | Scented Sachet (香囊) | carrying / wearing (no burn) |
| fumigation | Fumigation (熏香) | burning / fumigation |
| flower-scenting | Flower-Scenting (花熏香) | flower-steaming |
| no-flame-heating | No-Flame Heating (空熏) | heating (no flame) |
| single-material | Single-Material Appreciation (单方) | single-material appreciation |
| compound-formula | Compound Formula (复方) | compound-blending approach |
