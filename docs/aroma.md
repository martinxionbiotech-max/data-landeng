# Aroma Database

| Family | Members |

| Woody | 9 |
| Resinous | 4 |
| Sweet | 14 |
| Herbal | 4 |
| Spicy | 5 |
| Floral | 4 |
| Citrus | 2 |
| Earthy | 6 |
| Smoky | 1 |
| Balsamic | 5 |
